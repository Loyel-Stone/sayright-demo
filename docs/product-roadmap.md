# SayRight 产品路线图

## 当前公开站定位

SayRight Demo 是公开静态演示站，核心任务是让用户快速理解 SayRight 的价值：把中式英文改成更自然、更礼貌、更符合场景的英文。

公开站不承担真实 AI 调用，不收集 API Key，不做账号系统。

## 当前能力

| 模块 | 说明 |
|------|------|
| 中式示例 | 53 条内置示例，支持搜索、场景筛选、标签筛选 |
| 演示结果 | 本地预设双语结果，突出自然表达和场景表达 |
| 复制操作 | 支持复制语法修正、自然表达、场景表达、替代表达和完整结果 |
| 本地错误库 | 保存演示结果到 localStorage，可导入导出 |
| 参考例句库 | 5000 条静态中英参考句，支持搜索、筛选、收藏、复习 |
| 产品说明 | 隐私说明、反馈模板、开发路线展示 |

## 下一步：SayRight Desktop

桌面端承接公开站不提供的完整能力：

- 自定义句子真实 AI 分析
- 用户自带 DeepSeek API Key
- 更完整的错误库和历史记录
- 更好的桌面端布局、快捷键和本地体验
- 后续考虑更安全的本地密钥存储

公开 demo 只展示产品价值，桌面端负责真实使用场景。

## 后续形态

### 浏览器插件

- 面向 Gmail、Notion、GitHub、Google Docs 等网页写作场景
- 选中文本后触发纠错或改写
- 需要谨慎处理权限、隐私和不同网页 DOM 适配

### 手机端 App

- 面向移动办公、邮件草稿、旅行或留学场景
- 需要平衡输入效率、隐私合规和应用商店审核成本

### 输入法形态探索

- 长期方向
- 输入法权限极高，隐私风险最大
- 只有在本地模型、权限透明和退出机制足够成熟后才评估

## 暂不做

- 账号系统
- 在线支付系统
- 云端同步
- 公开网页内真实 AI 请求
- 运营方承担开放式 AI 调用成本
