# SayRight 产品与发行方向

当前 Mac 产品为 **v3.2 Internal RC**，未正式公开发行。当前没有公开新版 Mac Demo 安装包、正式版安装包或 TestFlight 邀请。

## 已确定方向，尚未实施的发行计划

- Private `sayright-desktop` 为唯一真实产品源码与产品事实来源。
- 免费 Mac Demo 将是功能受限、真正可安装的软件；正式版计划付费商业发行。
- 二者未来由同一私有产品代码基线构建，具体功能限制、定价、授权与交付日期尚未确定。
- Public `sayright-demo` 仅承载经审核的安装包和公开资料，不公开完整 Desktop 源码。
- `sayright` 保留为历史 Web 原型，不再作为新产品主线。
- TestFlight仅为未来测试渠道；经过验证且权利清晰的原创设计资产才考虑独立UI Kit开源。

旧网页 Demo 停止维护，D2–D6 本地成果保留作历史工程资产。不是继续开发网页业务、重建网页AI、创建试用授权/付费系统或自动同步Workflow的批准。

后续真实Mac Demo构建、产品限制、平台信任/安装包验收、公开许可、Commit/Push、Release发布分别需要具体授权。此处不承诺已上架App Store、已开放试用或确定发布日期。
