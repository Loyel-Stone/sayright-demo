# SayRight 公开演示版说明

## 目的

SayRight Demo 是公开静态演示站，用来展示「中式英文 -> 自然英文」的核心交互和产品价值。它不提供真实 AI 分析，不接收 API Key，也不包含后端服务。

## 演示范围

| 模块 | 说明 |
|------|------|
| 中式示例 | 53 条内置示例，覆盖通用、聊天、邮件、职场、学术、简历、社媒、技术、客服、产品描述 |
| 结果展示 | 本地预设结果，包含自然表达、场景表达、语法修正、中文解释、替代表达、错误标签、原句 |
| 参考例句 | 5000 条静态中英参考句 |
| 本地管理 | 收藏、复习、错误库、导入导出，全部保存在浏览器本地 |

## 不包含的能力

- 不调用真实 AI
- 不支持任意自定义句子分析
- 不配置 API Key
- 不提供账号系统
- 不上传用户内容
- 不包含 Electron、Express、`server.js`、`main.js` 或 `preload.js`

用户输入非内置示例时，页面会提示：

> 公开演示版仅支持内置示例。自定义句子请使用 SayRight Desktop，并配置自己的 DeepSeek API Key。

## 公开部署文件

```text
index.html
data_db.json
README.md
docs/
```

不要把 `.env`、真实 API Key、桌面端工程文件、后端文件或 `node_modules/` 放入公开 demo。

## 本地预览

```bash
python3 -m http.server 8000
```

打开 http://127.0.0.1:8000/
