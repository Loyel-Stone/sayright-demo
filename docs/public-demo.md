- Pages：旧网页展示已停用；停用不证明历史部署副本或第三方缓存已被清除。今后重新开启或替换展示需另行批准。

## 本地与公开边界

仓库只保留无脚本中性说明页，不提供案例、参考阅读、语料链接、API请求或新的浏览器学习功能。GitHub Pages 展示已停用，中性页不作为新的产品网站。今后若经 Owner 批准重新展示停用页，应只部署审核后的无语料提交树，并核对真实部署。

本地原始 JSON 仍保留，不应将含本地原件的完整 Checkout 直接作为发行静态根目录，因为被忽略原件仍可被普通静态服务器读到。公开材料应来自审阅后的提交树或明确白名单；不能复制本地原件和私有审计补丁。
