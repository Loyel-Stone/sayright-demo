💡 为什么做 SayRight

很多中文母语者不是不会英文，而是写出来容易带中文表达习惯。SayRight 想解决的不是背单词，而是把已经写出来的英文改得更自然、更礼貌、更符合场景。这是一个个人开发、免费演示、持续迭代的小工具。

🤖 它和普通 AI 聊天有什么区别？

🎯 更聚焦

专门处理中文母语者的英文表达问题，不是泛聊天。围绕中式表达、介词错误、语气生硬等高频问题设计。

📊 更结构化

结果拆分为修正版、自然表达、场景最佳表达、中文解释和错误标签，可以直接使用，不是一大段文字。

📚 更适合复习

改过的句子可以保存到个人错误库，后续复习、标记掌握、导出学习报告，不是改完就忘了。

📋 更适合收集

公开版内置 53 条高频中式英文示例，支持搜索、场景筛选和标签筛选，方便快速浏览和体验。

🔒 隐私友好设计

  • 当前没有账号系统，不需要注册或登录。
  • 个人错误库保存在浏览器 localStorage，不会自动上传到服务器。
  • 导出 JSON、导入 JSON、学习报告生成全部在本地浏览器完成。
  • 公开演示模式不会把示例体验内容上传到任何地方。

⚠️ 公开演示版不会分析自定义英文。需要真实纠错时，请使用 SayRight Desktop，并自行确认要发送给 AI 服务的内容不含高度敏感隐私。

📌 当前版本限制

  • 公开演示版只覆盖内置的 53 条示例，自定义英文请使用 SayRight Desktop 并配置自己的 DeepSeek API Key。
  • 当前没有账号同步，不同设备间的错误库需要通过导出/导入手动迁移。
  • 桌面端 App、浏览器插件和手机端仍在计划中，目前仅提供网页版。
  • AI 分析结果仅供参考，正式邮件、学术论文和合同等场景建议人工复核。

SayRight 是个人开发的早期版本，正在持续迭代。如果你有反馈或建议，欢迎通过反馈模板或 GitHub Issue 联系。

❓ 常见问题

这是免费的吗？
当前公开演示版可以免费体验 53 条内置示例，无需任何配置。自定义英文分析请使用 SayRight Desktop，并配置自己的 DeepSeek API Key。
为什么不直接用 ChatGPT？
ChatGPT 是很强的通用工具，但 SayRight 更聚焦在中文母语者的英文表达纠错。它把结果拆成修正版、自然表达、场景最佳表达、中文解释和错误标签，方便复习和积累。如果你需要的是垂直场景的英文纠错，SayRight 更顺手。
我的句子会被上传吗？
公开演示模式下，内置示例的体验内容完全在本地浏览器运行，不会上传。当前 SayRight 公开站没有服务器数据库，错误库只保存在你的浏览器本地。
为什么自定义句子不能在公开网页里直接分析？
因为公开网页没有后端，也不会收集或保存 API Key。直接在前端调用 AI 接口会暴露 Key，并产生不可控成本。桌面版会让用户在自己的 App 里填写自己的 Key，调用自己的额度。
错误库会不会丢？
错误库保存在当前浏览器的 localStorage 中。清理浏览器数据、换设备或换浏览器都会导致数据丢失。建议定期使用「导出 JSON」功能备份错误库，并保存到安全的地方。
后续会做什么？
计划包括桌面端 App（本地保存 API Key 和错误库）、浏览器插件（在网页输入框中直接改英文）、手机端和输入法形态探索。优先做桌面端，因为它最适合本地保存和全局快捷键唤起。详见页面底部的「开发路线」。
