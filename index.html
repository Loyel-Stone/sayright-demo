💡 为什么做 SayRight

很多中文母语者不是不会英文，而是写出来容易带中文表达习惯。SayRight 想解决的不是背单词，而是把已经写出来的英文改得更自然、更礼貌、更符合场景。这是一个个人开发、免费演示、持续迭代的小工具。

    ⚙️ 设置

    API Key 说明 当前可用

    当前默认使用本地后端 .env 中配置的 DeepSeek API Key。所有 AI 请求通过本地服务器转发，API Key 不会暴露给前端。

    如果你自己部署此项目，需要在项目根目录创建 .env 文件并填写 DEEPSEEK_API_KEY=你的Key。

    自带 API Key 待开发

    桌面版和浏览器插件版将支持用户填写自己的 DeepSeek API Key，无需依赖运营方承担 AI 成本。你的 Key 只保存在本地设备，不上传到任何服务器。

    此功能预计在桌面端 App v1.0 中提供。网页版出于安全考虑，暂不支持在浏览器中保存真实 API Key。

    公开演示版 v1.0

    当前 SayRight 以公开演示版形式发布。内置示例可直接体验纠错效果，无需任何配置。自定义英文需要真实 AI 模式（在 .env 中配置 DEEPSEEK_API_KEY）。未来桌面版将支持用户自带 API Key，无门槛使用完整功能。

    公开演示地址：https://loyel-stone.github.io/sayright-demo/

    v0.x 网页免费试用版 当前

    体验核心 AI 纠错和场景化改写能力，错误库本地存储。

    v1.0 桌面端 App 计划中

    完整错误库、本地历史记录、全局快捷键唤起、支持填写自己的 API Key。预计支持 macOS 和 Windows。

    v2.0 手机端 App 计划中

    移动端英文表达助手，支持 iOS 和 Android。

    v3.0 输入法形态探索 长期
